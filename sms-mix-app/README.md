# SMS Mix — Android v0.2.0 candidate

แอปส่ง SMS ผ่านซิม Android โดยนำเข้าเบอร์จาก CSV/TXT สุ่มแคปชั่นและลิงก์ แล้วส่งทีละเบอร์

## ชุดไฟล์ส่งมอบ

- `SMS-Mix-v0.2.0-source.zip` มีโฟลเดอร์ `android/` (โปรเจกต์นี้) และ `visiond-integration/` (แพตช์ API/ฐานข้อมูล/หน้าดูสิทธิ์ของ VisionD)
- `SMS-Mix-v0.2.0-debug.apk` อยู่ข้าง ZIP ในโฟลเดอร์ชุดส่งมอบ ไม่ได้อยู่ใน ZIP
- `manifest.json` ข้าง ZIP ระบุ SHA-256 ของ APK, ZIP และทุกไฟล์ซอร์ส
- เครื่องมือ build ต้องเตรียม JDK 17 และ Android SDK 35 ในเครื่องเอง; ไม่มี `.tools/` หรือ cache รวมใน ZIP

## ใช้งาน

1. ติดตั้ง APK บน Android 8.0 ขึ้นไปที่รองรับ SMS และเชื่อมต่ออินเทอร์เน็ต
2. ใส่คีย์ VisionD แล้วกดเปิดใช้งาน คีย์หนึ่งผูกได้หนึ่งเครื่อง การเปิดบนเครื่องใหม่เพิกถอนเครื่องเดิม
3. กดอนุญาต SMS / โหลดรายการซิม และเลือกซิม
4. เปิดสิทธิ์ตั้งเวลา (นาฬิกาปลุกและการช่วยเตือน บน Android 12 ขึ้นไป)
5. นำเข้าไฟล์ CSV/TXT แบบ UTF-8 ขนาดไม่เกิน 2 MB เบอร์อยู่คอลัมน์แรก
6. ใส่แคปชั่น 10–100 บรรทัด และลิงก์ HTTP(S) 10–100 บรรทัด จำนวนสองชุดต่างกันได้
7. สร้างคิว ตรวจพรีวิว แล้วกดเริ่มส่งและยืนยัน
8. หยุดชั่วคราว / ทำต่อ / ส่งออกบันทึก CSV ได้จากหน้าหลัก

บันทึกชุดแคปชั่นและชุดเบอร์ไว้ในเครื่องได้อย่างละไม่เกิน 20 ชุด การโหลด/ลบชุดไม่แก้คิวที่สร้างแล้ว
แอปตรวจสิทธิ์ออนไลน์เมื่อเปิดใช้งาน/ทำต่อ และทันทีก่อนส่ง SMS แต่ละรายการ หากออฟไลน์ คีย์หมดอายุหรือถูกย้ายเครื่อง คิวจะหยุดโดยคงรายการ PENDING ไว้ ไม่มีการส่งซ้ำอัตโนมัติของรายการที่ส่งเข้าระบบแล้ว

เบอร์แรกส่งทันทีหลังยืนยัน เบอร์ถัดไปสุ่มรอจำนวนเต็ม 10–30 นาทีจากเวลาส่งเบอร์ก่อนหน้า เลือกแคปชั่นและลิงก์แบบอิสระและสุ่มซ้ำได้ ข้อความจะถูกตรึงไว้ตอนสร้างคิวเพื่อให้ตรงกับพรีวิว การแก้ข้อความหรือเลือกซิมใหม่มีผลเมื่อสร้างคิวใหม่เท่านั้น

## ไฟล์เบอร์

ใช้คอลัมน์แรกเป็นเบอร์ มีหัวตาราง phone, phone_number, number, เบอร์ หรือ เบอร์โทร ได้ เบอร์ไทยมือถือ 06/08/09 จะเปลี่ยนเป็น +66; ต่างประเทศต้องใส่ +รหัสประเทศ รับ CSV แบบ quoted และ TXT หนึ่งเบอร์ต่อบรรทัด ตัดซ้ำหลังปรับรูปแบบ รองรับ 10,000 เบอร์ต่อคิว หากมีแถวไม่ถูกต้องจะไม่รับไฟล์ทั้งชุด และแสดงแถวที่ต้องแก้ ห้ามใช้รูปแบบเลขวิทยาศาสตร์จาก Excel

ไม่มีตัวอย่างเบอร์จริงในโปรเจกต์ เพื่อป้องกันการส่งถึงบุคคลอื่นโดยไม่ตั้งใจ

## สถานะและความต่อเนื่อง

- รอส่ง: ยังไม่ส่งให้ระบบโทรศัพท์
- รอผลจากระบบ: ส่งให้ระบบแล้ว กำลังรอ callback
- ส่งแล้ว: ทุกส่วนของ SMS ได้รับผลส่งสำเร็จจากระบบ ไม่ใช่ delivery/read receipt
- ส่งไม่สำเร็จ / บางส่วน: มีส่วนหนึ่งล้มเหลว คิวหยุด
- ไม่ทราบผล: ไม่มีผลภายใน 5 นาที หรือเกิดข้อผิดพลาดระหว่างส่ง คิวหยุดและไม่ส่งเบอร์นั้นซ้ำอัตโนมัติ

การทำต่อจะข้ามรายการที่ส่งแล้ว ล้มเหลว หรือไม่ทราบผล ส่งเฉพาะรอส่ง การสร้างคิวใหม่แทนที่ข้อมูลเก่าและอาจส่งถึงเบอร์เดิมได้ จึงมีคำเตือนก่อนแทนที่ ควรส่งออกบันทึกก่อน

คิวบันทึกแบบ atomic ก่อนส่ง SMS เพื่อหลีกเลี่ยงการส่งซ้ำหลังโปรเซสล่ม การหยุดไม่สามารถเรียกคืน SMS ที่ส่งให้ระบบแล้วได้ หลังรีบูตจะหยุดรอผู้ใช้กดทำต่อ Force-stop, ถอนสิทธิ์, เปลี่ยนเวลาเครื่อง และระบบประหยัดแบตเตอรี่ของผู้ผลิตอาจทำให้กำหนดส่งคลาดเคลื่อน ห้ามถือว่าเวลาจริงจะรับประกัน 10–30 นาทีทุกสถานการณ์

## Build

ต้องมี JDK 17, Android SDK Platform 35 และ Build Tools 35.0.0

เปิดโฟลเดอร์นี้ด้วย Android Studio หรือสร้าง local.properties ให้ชี้ SDK แล้วรัน:
    .\gradlew.bat assembleDebug lintDebug

ไฟล์: app/build/outputs/apk/debug/app-debug.apk
รุ่นนี้เป็น debug APK สำหรับทดสอบ/ติดตั้งโดยตรง ไม่ใช่ release ที่เซ็นด้วยคีย์สำหรับเผยแพร่ร้านค้า

ทดสอบ core (ไม่ใช้ Android SDK):
    .\test-core.ps1

## การตรวจบนเครื่องจริงก่อนใช้คิวเต็ม

ใช้เบอร์ที่คุณควบคุม 2–3 เบอร์ ทดสอบซิมที่เลือก, SMS ภาษาไทยหลายส่วน, ปิดหน้าจอรอช่วง 10–30 นาที, หยุด/ทำต่อ, ปิดแอป, รีบูต และกรณีไม่มีสัญญาณ ตรวจผลกับแอป SMS/โทรศัพท์ผู้รับ การทดสอบ build และ unit tests ไม่ทดแทนการทดสอบโมเด็มจริง

## ข้อมูลส่วนตัว

มี INTERNET permission เฉพาะการเปิดใช้งานและตรวจสิทธิ์กับ VisionD ส่งคีย์ รหัสเครื่องสุ่ม และรุ่นเครื่อง แต่ไม่ส่งรายชื่อ เบอร์ ข้อความ หรือแคปชั่นไปเซิร์ฟเวอร์ ปิด Android backup สำหรับข้อมูลแอป ไฟล์ส่งออกมีเบอร์และข้อความ ควรเก็บตามความเหมาะสม

APK ทดสอบนี้ใช้ Android debug certificate คนละใบกับ v0.1.0 เดิม จึงยังยืนยันการอัปเดตทับแอปเดิมโดยเก็บคิว/ชุดข้อมูลไม่ได้ ห้ามถอนแอปเดิมเพื่อทดลองโดยไม่สำรองข้อมูลก่อน
