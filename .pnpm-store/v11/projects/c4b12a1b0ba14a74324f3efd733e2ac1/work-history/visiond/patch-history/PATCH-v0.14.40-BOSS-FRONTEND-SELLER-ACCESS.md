# VisionD v0.14.40 — Boss Frontend Seller Access

- แก้ ELON ที่เคยมองบัญชี Boss เป็นสมาชิกทั่วไปเมื่อถามวิธีขายคอร์ส
- Boss ได้สิทธิ์คำแนะนำเมนู Frontend ฝั่งผู้ขายคอร์สอัตโนมัติ
- ไม่ส่ง role, คำว่า Boss, สถานะ Admin หรือสิทธิ์หลังบ้านเข้า AI
- ข้อมูลที่ AI เห็นยังคงเป็น boolean ขั้นต่ำ `can_use_seller_vision5: true`
- คำถามฐานข้อมูล หลังบ้าน Admin Secret และระบบภายในยังถูกบล็อกเหมือนเดิม
