# PATCH v0.14.335 — UI Design Contract Protocol

- เพิ่มโปรโตคอลเฉพาะงาน Frontend/UI โดยอ้าง canonical button/design system ที่มีอยู่จริง
- ล็อก variant, size, interaction, accessibility และ Desktop/Mobile evidence
- หากต้องสร้าง token, variant หรือ component ใหม่ Codex ต้องหยุดแจ้ง Boss ก่อน
- Active Protocol โหลดเอกสารนี้เฉพาะเมื่อแตะ UI จึงไม่เพิ่มภาระแพต backend/document อื่น
