# PATCH v0.14.154 — Event Case Stability

- ติดตั้งด้วยการแตก ZIP แล้ววางทับอย่างเดียว ไม่ย้าย/ลบโฟลเดอร์และไม่เปลี่ยน Cloudflare
- ตัวตรวจ migration ยอมรับไฟล์เลขซ้ำเฉพาะกรณีเนื้อหาเหมือนกันทุกไบต์; ถ้าเนื้อหาต่างกันยังบล็อก deploy
- Regression runner รันเฉพาะสัญญาที่ออกแบบให้ใช้ข้ามเวอร์ชัน และแยก snapshot ของแพตเก่าเป็น SKIP แทนบั๊กปลอม
- เพิ่ม V5 rights-to-learning contract แบบฐานข้อมูลในหน่วยความจำ ครอบคลุมซื้อสิทธิ์ 499, เครดิต, ตะกร้า, เผยแพร่, สิทธิ์เรียน และการอนุมัติซ้ำ
- `user1` และตะกร้าตัวอย่างเป็นข้อมูลสงวนสำหรับ Event Case: อ่านและตรวจได้ แต่ห้ามลบ รีเซ็ต หรือสร้างทับ
- แพตนี้ไม่เรียก migration หรืองานล้างข้อมูลทดสอบใด ๆ

EVENT CASE: ยังไม่เสร็จ — ต้องแพตต่อ
