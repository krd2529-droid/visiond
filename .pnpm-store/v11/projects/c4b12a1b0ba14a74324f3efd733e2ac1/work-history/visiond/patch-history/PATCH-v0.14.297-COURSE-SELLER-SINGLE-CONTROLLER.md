# v0.14.297 — ลบโครงสร้างซ้อนหน้าสร้างคอร์ส

- พบสาเหตุจริงว่า `course-seller.html` โหลดตัวควบคุมฟอร์มและ EP สองชุดพร้อมกัน ทำให้ชุดเก่าเขียนปุ่มและสถานะทับชุดใหม่หลังรีเฟรช
- ลบตัวควบคุม EP แบบร่างเก่า, ตัวเสริมเครดิตเก่า และตัวสร้างปุ่มเก่าจากโค้ดจริง ไม่ใช้ CSS ซ่อน
- ให้ `course-seller.js` เป็นเจ้าของขั้นตอนบันทึกตะกร้า จัดการ EP และส่งตรวจเพียงไฟล์เดียว
- ตัด alias `type=2` เก่า เหลือเส้นทางปัจจุบัน `type=1` สำหรับพาร์ตเนอร์เท่านั้น
- ตัด payload บัญชีรับเงินและ EasySlip Token เก่าออกจาก API ของหน้าจัดการคอร์ส
- เพิ่ม regression test ป้องกันการนำไฟล์เก่าหรือตัวควบคุมซ้อนกลับมาอีก
