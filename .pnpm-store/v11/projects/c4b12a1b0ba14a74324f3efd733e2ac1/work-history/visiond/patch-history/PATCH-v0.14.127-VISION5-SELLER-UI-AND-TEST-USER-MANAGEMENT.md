# PATCH v0.14.127 — Vision 5 Seller UI + Test User Management

วันที่: 2026-08-11

## งานที่เสร็จ

1. เปลี่ยน Checkbox ตรวจสลิปเป็นสวิตช์เปิด–ปิด พร้อมข้อความสถานะตรวจอัตโนมัติ/ตรวจเอง
2. เพิ่ม `ยูสเทส` เป็นประเภทบัญชีในหลังบ้าน โดยคงสิทธิ์ระดับ User และไม่ปะปนกับ Vision 5 test flag
3. Boss แก้ชื่อ อีเมล Username เบอร์โทร และประเภทบัญชีทั้งแถวได้ พร้อม validation และ Audit ค่าเดิม–ค่าใหม่
4. หน้าเพิ่มและแก้ไขตะกร้าแสดง Preview รูปปก 16:9 ก่อนบันทึก พร้อมเปลี่ยน/คืนรูปเดิม
5. ตัดช่องระดับผู้เรียนออกจาก UI และกำหนด `all` ภายใน
6. การ์ด `ตะกร้าคอร์สของฉัน` แสดงปก ชื่อ ผู้สอน ราคา EP สถานะ และวันแก้ไข พร้อมลำดับปุ่มที่ชัดเจนและมือถือเต็มความกว้าง
7. ตัวจัดการ EP ซ่อนฟอร์มไว้ก่อน มีปุ่ม `+ สร้าง EP เพิ่ม` และเปิดฟอร์มเฉพาะตอนสร้าง/แก้ไข

## กฎความปลอดภัย

- ตารางสมาชิกไม่แก้ User ID, Password hash, วันที่สร้าง, ออเดอร์ หรือประวัติสิทธิ์
- บัญชี Boss แก้ผ่านตารางนี้ไม่ได้
- อีเมลและ Username ห้ามซ้ำ ชื่อทั่วไปห้ามซ้ำ แต่ยูสเทสใช้ชื่อ `รัฐสิทธิ ดำรงรถการ` ซ้ำได้
- เครดิตยังใช้ Ledger และปุ่มเพิ่มเครดิตเดิม ไม่เขียนทับตัวเลขคำนวณโดยตรง
