# PATCH v0.14.187 — TEMPLATE และปุ่มมาตรฐาน

## Event Case

ทำมาตรฐาน Template และปุ่ม VisionD ให้ครบทุกหน้า รวมมือถือ โดยไม่เปลี่ยน handler หรือ API เดิม

## สิ่งที่แก้

- เพิ่ม CSS ปุ่มกลางที่โหลดเป็นชั้นสุดท้ายและใช้สี Tiffany ชุดเดียว
- เพิ่ม runtime จัดประเภทปุ่มเดิมและปุ่มที่สร้างแบบ dynamic
- ยกเว้นปุ่ม backdrop ที่มีหน้าที่ควบคุม layout
- ผูกมาตรฐานครบ HTML 38 หน้า และเพิ่ม regression guard ป้องกันหน้าหรือปุ่มใหม่หลุดระบบ
