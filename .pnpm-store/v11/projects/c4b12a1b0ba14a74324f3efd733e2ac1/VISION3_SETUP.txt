VISION 3 — ตรวจสลิปและปลดล็อกอัตโนมัติ

1. สมัคร EasySlip และเพิ่มบัญชีรับเงินที่ VisionD ใช้ทุกบัญชี
   https://developer.easyslip.com/

2. ใน Cloudflare Pages > visiond > Settings > Variables and Secrets
   เพิ่ม Secret ชื่อ: EASYSLIP_API_KEY
   ค่า: API Key จาก EasySlip
   ห้ามใส่คีย์ลงในไฟล์หรือ GitHub

3. Commit/Push ไฟล์ชุดนี้ แล้วรอ Deployment สำเร็จ

4. สร้างออเดอร์ทดสอบใหม่หลังอัปเดต (ออเดอร์เก่าไม่มีข้อมูลบัญชี ณ เวลาสั่งซื้อ
   จึงจะถูกส่งให้ตรวจด้วยมือเพื่อความปลอดภัย)

5. ทดสอบอย่างน้อย 5 กรณี
   - สลิปจริง ยอดตรง บัญชีตรง: ปลดล็อกอัตโนมัติทั้งออเดอร์
   - ยอดไม่ตรง: ไม่ปลดล็อก
   - โอนผิดบัญชี: ไม่ปลดล็อก
   - ใช้สลิปซ้ำ: ไม่ปลดล็อก
   - EasySlip/API ขัดข้อง: ไม่ปลดล็อกและรอ Boss/Admin ตรวจ

ระบบจะทำงานแบบ Fail Closed: หากยืนยันไม่ครบทุกข้อ จะไม่ปลดล็อกอัตโนมัติ
