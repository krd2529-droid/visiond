# คลิกอัตโนมัติ ภาษาไทย 1.0.0

แอป Windows 64-bit แบบพกพา ใช้ .NET Framework ที่มีใน Windows เครื่องนี้ ไม่ต้องสมัครบัญชี ไม่เสียเงิน และไม่มีข้อจำกัดจำนวนจุดแบบแพ็กเกจเสียเงิน

## เปิดใช้งาน

ดับเบิลคลิก `Start.cmd` หรือ `dist/ThaiAutoClicker.exe` ถ้ายังไม่มี EXE ตัวเปิดจะสร้างให้จากซอร์สด้วย compiler ของ Windows

1. กด **เพิ่มจุด** แล้วลากวงกลมหมายเลขไปวางบนตำแหน่งที่ต้องการคลิก จุดคลิกอยู่ตรงกลางวงกลม
2. เพิ่มจุดอื่นตามต้องการ แก้ X/Y และ **รอหลังคลิก (ms)** ในตารางได้ เวลา 1000 ms คือ 1 วินาที ต่ำสุด 50 ms สูงสุด 24 ชั่วโมง
3. ใช้ **ขึ้น/ลง** เพื่อเปลี่ยนลำดับ หรือ **ลบจุดที่เลือก** ลบจุด
4. ตั้งจำนวนรอบ ค่า 1 คือหนึ่งรอบ ค่า **0 คือวนจนกว่าจะหยุด**
5. กด **เริ่ม** มีเวลานับถอยหลัง 3 วินาทีให้สลับไปหน้าต่างเป้าหมาย วงกลมจะซ่อนขณะทำงาน คลิกซ้ายเรียงตามตาราง และรอตามเวลาของจุดที่เพิ่งคลิก ก่อนคลิกถัดไป (จบงานทันทีหลังคลิกสุดท้ายของรอบสุดท้าย)
6. กด **Ctrl + Shift + F12** ได้แม้อยู่ในโปรแกรมอื่นเพื่อหยุดทันที หรือกดปุ่ม **หยุด** การปิดแอปหยุดงานด้วย

**แถบลอย** เปิดปุ่มเพิ่มจุด/เริ่ม/หยุดแบบอยู่เหนือหน้าต่างอื่น ลากแถบชื่อเพื่อย้ายตำแหน่ง ควรวางแถบและหน้าต่างหลักให้พ้นจุดคลิก

**บันทึกชุด/เปิดชุด** เก็บพิกัด เวลารอ และจำนวนรอบเป็น JSON ในเครื่อง การเปิดชุดไม่เริ่มคลิกเอง ตรวจพิกัดอีกครั้งหลังย้ายหน้าต่าง เปลี่ยนจอ หรือปรับความละเอียด พิกัดนอกจอและไฟล์ผิดรูปแบบจะถูกปฏิเสธ รองรับจอหลายจอ รวมพิกัดติดลบ

หากจองปุ่มหยุดฉุกเฉินไม่ได้ แอปจะไม่ยอมเริ่ม ให้ปิดแอปอื่นที่ใช้ปุ่มนี้แล้วเปิดใหม่ แอปคลิกตามตำแหน่งบนจอ ไม่ค้นหาปุ่มจากภาพและไม่ติดตามหน้าต่างที่ย้าย Windows อาจบล็อกการคลิกโปรแกรมที่เปิดแบบผู้ดูแลระบบหรือหน้าจอที่ถูกล็อก

## สร้างและทดสอบ

รัน `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1` เพื่อสร้าง EXE ซ้ำโดยไม่ดาวน์โหลดแพ็กเกจ

รันทดสอบด้วย PowerShell:

```powershell
$p = Start-Process -FilePath .\dist\ThaiAutoClicker.exe -ArgumentList '--self-test', 'self-test.txt' -PassThru
$p.WaitForExit(15000)
Get-Content .\self-test.txt
```

การทดสอบเปิดหน้าต่างเป้าหมายของตัวเองแล้วคลิก A/B สี่ครั้งเท่านั้น จะไม่ส่งคลิกถ้าหน้าต่างเป้าหมายไม่ได้อยู่ด้านหน้า ทดสอบลำดับ เวลา จำนวนรอบ การหยุดระหว่างรอ/นับถอยหลัง การบันทึก/เปิดชุด และการปฏิเสธพิกัดผิดด้วย ระหว่างทดสอบไม่ควรขยับเมาส์หรือสลับหน้าต่าง

ถ้า Windows ไม่ยอมให้หน้าต่างทดสอบขึ้นด้านหน้า ใช้ `--interactive-test` แทน `--self-test` แล้วกด **BEGIN SAFE TEST** ในหน้าต่างทดสอบ จะนับถอยหลัง 3 วินาทีก่อนเริ่มคลิกและปิดเองเมื่อทดสอบเสร็จ

การตั้งค่าจอหลายจอที่ใช้สเกลต่างกันยังไม่ได้ทดสอบกับจอจริงครบทุกแบบ ควรทดลองกับหน้าต่างทดสอบก่อนใช้งานชุดพิกัดดังกล่าว

ไฟล์โปรแกรมไม่ติดต่อเครือข่ายและไม่เก็บรหัสผ่าน พิกัดที่บันทึกอยู่ในไฟล์ที่คุณเลือกเอง
