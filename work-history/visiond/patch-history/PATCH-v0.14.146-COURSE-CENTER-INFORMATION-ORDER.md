# PATCH v0.14.146 — Course Center Information Order

## ผลลัพธ์

- หัวข้อใหญ่ `ศูนย์จัดการคอร์ส` อยู่บนสุด
- ลำดับใช้งานเป็น สรุปยอดขาย → รับเงิน/ตรวจสลิปและออเดอร์ → สร้างคอร์ส/เครดิต → คอร์สของฉัน → ตารางลูกค้า/สลิป/ยอดรวม
- ตารางยอดขายแสดงลิงก์สลิปจริงเฉพาะรายการที่มีสลิป
- ลบ CSS เก่าที่ซ่อนตารางและบังคับลำดับคนละแบบกับ DOM

## Compatibility

- คง ID และ event hooks ของปุ่ม/ฟอร์มเดิม
- ไม่เปลี่ยน schema และไม่เพิ่มข้อมูลส่วนบุคคลใน response
