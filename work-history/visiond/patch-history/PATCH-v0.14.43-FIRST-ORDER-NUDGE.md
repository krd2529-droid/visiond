# v0.14.43 — โปรโมชั่นกระตุ้นการซื้อครั้งแรก

- ล็อกอินสำเร็จครั้งที่ 2: แจ้งเตือนของขวัญสมาชิกใหม่
- ล็อกอินสำเร็จครั้งที่ 3: เปิดสิทธิ์ 2 ชั่วโมง ลดอัตโนมัติ 50% สูงสุด 200 บาท
- ต้องมียอดสินค้าที่ร่วมรายการ 399 บาทขึ้นไป
- สิทธิ์ลงขายคอร์สออนไลน์ไม่ร่วมรายการและไม่นับยอดขั้นต่ำ
- ไม่ซ้อนกับส่วนลดหลายตะกร้า ระบบเลือกส่วนลดลูกค้าใหม่ก่อนเมื่อเข้าเงื่อนไข
- คำนวณและบันทึกส่วนลดจากเซิร์ฟเวอร์ บอสไม่ต้องอนุมัติ
- เก็บ login และการใช้สิทธิ์ใน user_activity_log; ประวัติก่อนแพตช์ไม่สามารถสร้างย้อนหลังได้
- ซื้อสำเร็จหรือใช้สิทธิ์สร้างออเดอร์แล้วจะไม่แจกซ้ำ
- เพิ่มกระดิ่งแจ้งเตือนบนแถบเมนู พร้อมจุดแดง จำนวนรายการใหม่ แผงเปิดดู และปุ่มรับทราบ รองรับมือถือ
- อัปเดตบริบท ELON: โปรนี้เป็นข้อมูลหน้าร้านเท่านั้น ELON อธิบายได้ แต่ไม่มีสิทธิ์คำนวณ อนุมัติ หรือแก้ราคา
