VisionD v0.11.0 - เชื่อม Google Gemini Image

1. Cloudflare Dashboard > Workers & Pages > visiond > Settings
2. ไปที่ Variables and secrets แล้วกด Add
3. เลือก Secret
4. Variable name: GEMINI_API_KEY
5. Value: API Key จาก Google AI Studio
6. Save แล้ว Retry deployment หรือ Deploy ใหม่

R2 binding ที่ต้องมีอยู่แล้ว:
- Variable name: FILES
- R2 bucket: visiond-files

ใน Vision 2 ให้เลือก Google Imagen API ระบบจะเรียกโมเดล
gemini-3.1-flash-image สร้างภาพจริง เก็บลง R2 และแสดงในช่องรูปอัตโนมัติ
