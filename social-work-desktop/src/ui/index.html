ร่างข้อความด้วย OpenAI

ใช้คีย์ OpenAI API ของคุณเอง: ใน Windows ค้นหา “แก้ไขตัวแปรสภาพแวดล้อมสำหรับบัญชีของคุณ” → เพิ่มตัวแปรผู้ใช้ชื่อ OPENAI_API_KEY และใส่ค่า → ปิดและเปิดแอปใหม่ ห้ามส่งคีย์ทางแชต คีย์จะไม่ถูกบันทึกในฐานข้อมูลหรือส่งมายังหน้านี้ การทดสอบจะเรียก API จริงและอาจมีค่าใช้จ่ายเล็กน้อย
