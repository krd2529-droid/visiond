V-Record 0.6.0 สำหรับ Windows

1. ดาวน์โหลดชุด V-Record จากหน้า "โปรแกรมของฉัน" ในบัญชี VisionD แล้วแตก ZIP ทั้งชุดไว้ในโฟลเดอร์เดียวกัน
2. เปิด V-Record.exe ก่อน แอปตรวจลายเซ็นและแฮชไฟล์ในชุดนี้ แล้วกดปุ่ม "ติดตั้ง FFmpeg" ในหน้าหลัก แอปตรวจชุดอีกครั้งก่อนเปิดสคริปต์ติดตั้งที่ลงลายเซ็นไว้
   สคริปต์ดาวน์โหลด FFmpeg 9.0.2 essentials จาก https://www.gyan.dev/ffmpeg/builds/ โดยตรง แล้วตรวจ SHA-256 ของ ZIP และ ffmpeg.exe ก่อนติดตั้งลงโฟลเดอร์ tools
   อย่ารัน Install-FFmpeg.ps1 โดยตรงจาก ZIP หรือโฟลเดอร์ที่ยังไม่ผ่านการตรวจของแอป
   หากผู้เผยแพร่อัปเดตไฟล์จนแฮชไม่ตรง สคริปต์จะหยุดโดยไม่ติดตั้ง ให้ติดต่อ VisionD เพื่อรับสคริปต์ที่ผ่านการตรวจรุ่นใหม่
3. เปิด V-Record.exe แล้วใส่คีย์จากหน้า "โปรแกรมของฉัน" ในเมนู "ใบอนุญาต"
4. เชื่อมต่ออินเทอร์เน็ตเพื่อเปิดใช้และตรวจสิทธิ์เป็นระยะ แอปเก็บใบอนุญาตที่ลงนามไว้ใช้ออฟไลน์ได้ไม่เกิน 7 วัน และไม่เกินวันหมดอายุ

V-Record ไม่รวม FFmpeg ในไฟล์ที่ VisionD แจกจ่าย FFmpeg จะถูกดาวน์โหลดจากผู้เผยแพร่ตามขั้นตอนที่ 2 เท่านั้น
หลังติดตั้ง อ่านเงื่อนไข GPLv3 และข้อมูล build/source ของผู้เผยแพร่ใน tools/FFmpeg-LICENSE.txt และ tools/FFmpeg-README.txt
ซอร์ส FFmpeg ที่ผู้เผยแพร่ระบุสำหรับ build นี้: https://github.com/FFmpeg/FFmpeg/commit/946fcce07b

คีย์ทดลอง 7 วันเริ่มนับเมื่อขอรับคีย์ แพ็กเกจ 30 วัน/365 วันเริ่มนับเมื่อ VisionD ยืนยันการชำระเงิน ไม่ใช่เมื่อเปิดแอปครั้งแรก
คีย์ V-Record ใช้ได้ 1 เครื่อง หากเปลี่ยนเครื่องให้ติดต่อ VisionD เพื่อจัดการสิทธิ์

ถ้าแอปแจ้งว่า FFmpeg ยังไม่พร้อม ให้กดปุ่ม "ติดตั้ง FFmpeg" ในแอปอีกครั้ง และเปิดแอปใหม่หลังติดตั้งเสร็จ
อย่าย้าย V-Record.exe ออกจากชุด หรือใช้ ffmpeg.exe จากแหล่งอื่นแทนไฟล์ที่สคริปต์ตรวจแฮชแล้ว
