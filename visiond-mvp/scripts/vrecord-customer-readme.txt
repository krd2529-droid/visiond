V-Record 0.6.0 สำหรับ Windows

1. ดาวน์โหลดชุดติดตั้งจากหน้า "โปรแกรมของฉัน" ในบัญชี VisionD ของคุณ
2. แตก ZIP ทั้งชุดไว้ในโฟลเดอร์เดียวกัน ห้ามย้าย V-Record.exe ออกไปเดี่ยว ๆ
3. เปิด V-Record.exe แล้วใส่คีย์จากหน้า "โปรแกรมของฉัน" ในเมนู "ใบอนุญาต"
4. เชื่อมต่ออินเทอร์เน็ตเพื่อเปิดใช้และตรวจสิทธิ์เป็นระยะ แอปเก็บใบอนุญาตที่ลงนามไว้ใช้ออฟไลน์ได้ไม่เกิน 7 วัน และไม่เกินวันหมดอายุ

คีย์ทดลอง 7 วันเริ่มนับเมื่อขอรับคีย์ แพ็กเกจ 30 วัน/365 วันเริ่มนับเมื่อ VisionD ยืนยันการชำระเงิน ไม่ใช่เมื่อเปิดแอปครั้งแรก
คีย์ V-Record ใช้ได้ 1 เครื่อง หากเปลี่ยนเครื่องให้ติดต่อ VisionD เพื่อจัดการสิทธิ์

ชุดนี้รวม FFmpeg 9.0.2 essentials build จาก Gyan.dev ภายใต้ GPLv3
อ่านเงื่อนไขใน tools/FFmpeg-LICENSE.txt และรายละเอียด build/source ใน tools/FFmpeg-README.txt
ซอร์ส FFmpeg ที่ตรงกับ build: https://github.com/FFmpeg/FFmpeg/commit/946fcce07b
หน้าผู้เผยแพร่ build: https://www.gyan.dev/ffmpeg/builds/

หากโปรแกรมไม่เปิด ให้ตรวจว่าไฟล์ V-Record.exe, V-Record.Updater.exe, package-manifest.json และโฟลเดอร์ tools อยู่ครบ และดาวน์โหลดใหม่จากบัญชี VisionD
