# VisionD MVP

## v0.14.00 — อัปโหลด EP แรกพร้อมสร้างคอร์สร่าง

- เพิ่มช่องคลิป วิดีโอ เอกสาร ชื่อและรายละเอียด EP.1 ในฟอร์มสร้างคอร์สร่าง
- ระบบสร้างคอร์สร่างก่อน แล้วอัปโหลด EP.1 ให้อัตโนมัติในคำสั่งเดียว
- การอัปโหลด EP.1 เป็นตัวเลือก ผู้ขายยังสามารถเว้นไว้แล้วเพิ่มภายหลังได้

## v0.13.99 — ปรับปุ่มเมนูสมาชิกหน้าแรก

- นำปุ่มติดต่อ LINE ออกจากแถบเมนูด้านบน เพราะมีส่วนติดต่อด้านล่างหน้าแล้ว
- ปรับสินค้าของฉัน รถเข็น หลังบ้าน และออกจากระบบให้เป็นปุ่มทรงเดียวกันพร้อมไอคอน

## v0.13.98 — ปรับปุ่มเลือกรายชื่อลูกค้า

- ช่องเลือกลูกค้าใน Manual Unlock กะทัดรัด ไม่ยืดสูงตามกล่องเลือกหลายสินค้า
- เพิ่มไอคอน กรอบ และสถานะ hover/focus ให้ดูชัดและใช้งานง่ายขึ้น

## v0.13.97 — ซื้อสิทธิ์หลายชิ้นในตะกร้าเดียว

- หน้าสิทธิ์ลงขายคอร์สมีปุ่มลด/เพิ่มและช่องจำนวน ซื้อได้ 1–30 สิทธิ์ต่อออเดอร์
- รถเข็นรวมสิทธิ์เป็นรายการเดียว แสดงจำนวน เครดิตที่จะได้รับ และยอดรวมทันที
- ฝั่ง API สร้างรายการสิทธิ์ตามจำนวนจริง และเพิ่มเครดิตเท่าจำนวนเมื่อสลิปผ่าน
- เปลี่ยนเลขเวอร์ชันไฟล์ JavaScript เพื่อบังคับเบราว์เซอร์โหลดหน้าจอจำนวนสิทธิ์ล่าสุด

## v0.13.65 — ราคาเต็ม 999 ลดเหลือ 499 และแยกโปร

- ทำรูปปกใหม่ แสดงราคาเต็ม 999 บาทขีดฆ่า และราคา 499 บาทเด่น
- การ์ดหน้าแรกมีเพียงปุ่ม “ใส่รถเข็น” และ “ดูสินค้า”
- เพิ่มหมายเหตุว่าตะกร้าสิทธิ์ไม่ร่วมโปรส่วนลดกับตะกร้าใด ๆ
- ไม่ใช้ตะกร้าสิทธิ์นับจำนวนสินค้าเพื่อปลดล็อกส่วนลด 5/10/20/30 ตะกร้า
- ไม่หักส่วนลดแบบจัดชุดจากราคา 499 บาท ทั้งหน้าเว็บและฝั่งสร้างออเดอร์
- ราคา 999 → 499 เป็นราคาพิเศษเฉพาะตะกร้าสิทธิ์และแสดงในหน้ารายละเอียดสินค้า
- เปลี่ยนชื่อไฟล์รูปปกอีกครั้งเพื่อป้องกันแคชรูปเดิม

## v0.13.64 — เพิ่มกติกาภาพปกคอร์สในตะกร้าสิทธิ์

- เพิ่มกล่อง “กติกาภาพปกคอร์ส” ในหน้ารายละเอียดตะกร้าสิทธิ์ให้อ่านง่าย
- ห้ามใช้โลโก้ เครื่องหมายการค้า ภาพหน้าจอ หรือสื่อของแบรนด์อื่นเป็นภาพปก เว้นแต่มีหนังสืออนุญาตและผ่านการตรวจ
- อนุญาตให้พิมพ์ชื่อแพลตฟอร์มเป็นข้อความธรรมดาเพื่อบอกหัวข้อที่สอน
- ห้ามออกแบบให้เข้าใจว่าเป็นคอร์สทางการหรือได้รับการรับรองจากแบรนด์
- VisionD สงวนสิทธิ์ขอเปลี่ยนหรือระงับภาพปกที่เสี่ยงละเมิดสิทธิ์
- ระบบเพิ่มกติกานี้ในรายละเอียดตะกร้าเดิมอัตโนมัติเพียงครั้งเดียว

## v0.13.63 — เปลี่ยนรูปปกเป็นชื่อสิทธิ์เต็ม

- เปลี่ยนข้อความบนรูปปกหลักเป็น “สิทธิ์ลงขายคอร์สออนไลน์”
- ใช้ชื่อไฟล์รูปใหม่เพื่อป้องกันเบราว์เซอร์แสดงรูปเก่าจากแคช
- อัปเดตรูปปกและรูปตัวอย่างของตะกร้าเดิมในฐานข้อมูลอัตโนมัติ
- ปรับชื่อหมวด ชื่อตะกร้า และข้อความที่เกี่ยวข้องให้ใช้ “สิทธิ์ลงขายคอร์สออนไลน์” อย่างสม่ำเสมอ
- แก้ลิงก์ซื้อสิทธิ์เพิ่มให้เข้าหน้ารายละเอียดตะกร้าปกติ

## v0.13.62 — เน้นจุดขายรับยอดเต็มไม่หักเปอร์เซ็นต์

- เพิ่มป้ายจุดขายขนาดใหญ่ “รับยอดขายเต็ม ไม่หัก %” บนการ์ดสิทธิ์ลงขายคอร์สหน้าแรก
- ใช้สีทองตัดกับพื้นเขียวเพื่อให้เห็นก่อนรายละเอียดอื่นทั้งคอมและมือถือ
- เพิ่มข้อความ “เงินเข้าช่องทางของเจ้าของคอร์ส” ในจุดเด่นของการ์ด

## v0.13.61 — จัดหน้าแรกใหม่และแยกสิทธิ์ขายคอร์ส

- จัดหน้าแรกตามลำดับ: แบนเนอร์ → การ์ดสิทธิ์ลงขายคอร์ส → คอร์สออนไลน์ → สินค้าดิจิทัล → ติดต่อ
- เพิ่มการ์ดสิทธิ์ลงขายคอร์สออนไลน์ขนาดใหญ่สำหรับเจ้าของคอร์สโดยเฉพาะ พร้อมราคาและปุ่มเข้าหน้าตะกร้าปกติ
- ราคาและรูปปกในการ์ดพิเศษอ่านจากสินค้าที่แก้ไขในหลังบ้าน
- ซ่อนตะกร้าสิทธิ์จากแคตตาล็อกสินค้าดิจิทัลเฉพาะหน้าแรก เพื่อไม่ให้แสดงซ้ำกับการ์ดพิเศษ
- หน้าคอร์สเรียนแสดงเฉพาะคอร์สสำหรับผู้เรียน ไม่แสดงตะกร้าสิทธิ์ขายคอร์ส
- เพิ่มส่วนช่องทางติดต่อท้ายหน้าแรก

## v0.13.60 — หน้าแรกแนะนำสินค้าดิจิทัลทุกหมวด

- เปลี่ยนหัวข้อหน้าแรกจาก “แบบรอยสักแนะนำ” เป็น “สินค้าดิจิทัลแนะนำ”
- เปลี่ยนลิงก์ด้านขวาเป็น “ดูสินค้าดิจิทัลทั้งหมด” และเปิดแคตตาล็อกทุกหมวด
- เปลี่ยนคำกำกับภาษาอังกฤษเป็น `RECOMMENDED DIGITAL PRODUCTS`

## v0.13.59 — เพิ่มภาพเงื่อนไขตะกร้าสิทธิ์ 2 พาร์ต

- เพิ่มอินโฟกราฟิกแนวตั้งสำหรับมือถือ พาร์ต 1 “สิ่งที่จะได้รับ” และพาร์ต 2 “เงื่อนไขสำคัญ”
- นำรูปทั้งสองไปต่อท้ายรูปปกของตะกร้าสิทธิ์ลงขายคอร์สโดยอัตโนมัติ
- ลูกค้าปัดดูรูปปกและรูปเงื่อนไขครบ 3 รูปก่อนตัดสินใจซื้อได้

## v0.13.58 — ตะกร้าสิทธิ์ใช้รูปแบบสินค้าดิจิทัลและแก้จากหลังบ้านได้

- ตะกร้าสิทธิ์ลงขายคอร์สแสดงด้วยการ์ด รูป ราคา ปุ่มรถเข็น และหน้ารายละเอียดแบบเดียวกับสินค้าดิจิทัล
- แอดมินสร้างแพ็กเกจสิทธิ์ใหม่ได้จากหน้าจัดการคอร์ส โดยเลือกชนิด “สิทธิ์ลงขายคอร์ส”
- แก้ชื่อ ราคา รูป รายละเอียด หมวด และสถานะขายได้จากหน้าจัดการสินค้าปกติ
- คอร์สออนไลน์จริงยังคงแยกอยู่ในหน้าแคตตาล็อกคอร์สออนไลน์

## v0.13.57 — สร้างตะกร้าสิทธิ์ลงขายคอร์สอัตโนมัติ

- สร้างและเปิดขายตะกร้า “สิทธิ์ลงขายคอร์ส 1 ตะกร้า แก้ไขได้ 30 วัน” ราคา 499 บาทอัตโนมัติหลัง Push
- ใช้รูปปกแนวตั้งสำหรับมือถือและแสดงในหมวดสิทธิ์ลงขายคอร์สทันที
- คำสั่งสร้างแบบป้องกันรายการซ้ำ จึง Push ซ้ำได้โดยไม่เกิดตะกร้าซ้ำ

## v0.13.56 — เปลี่ยนชื่อหมวดเป็นสิทธิ์ลงขายคอร์ส

- ใช้ชื่อ “สิทธิ์ลงขายคอร์ส” ให้ตรงกันทั้งหน้าร้าน หลังบ้าน ตะกร้า และแดชบอร์ดผู้ขาย
- ปรับรูปปกสินค้าเป็นแนวตั้งสำหรับการเปิดดูบนมือถือ

## v0.13.55 — สิทธิ์ลงขายคอร์สและแดชบอร์ดยอดขาย (ยังไม่ส่งอีเมล)

- เพิ่มแพ็กเกจสิทธิ์ลงขายคอร์ส 30 วัน, 1 ปี และตลอดอายุระบบ โดย 1 สิทธิ์ผูกกับ 1 ตะกร้าถาวรและลบแล้วไม่คืนสิทธิ์
- ผู้ซื้อสิทธิ์สร้างคอร์ส กรอกข้อมูลรับเงิน อัปโหลดรูปปก คลิป และเอกสาร PDF/DOCX/XLSX/PPTX/ZIP แยกตาม EP ได้
- คอร์สของผู้ขายรับชำระเข้าบัญชีหรือ QR ของเจ้าของคอร์ส และแอดมินยังตรวจสลิปแบบแมนนวล
- เพิ่มหน้าผู้ขายสำหรับยอดขายรวม จำนวนออเดอร์ รายการยอดขาย และวันเวลา
- ยังไม่เปิดการแจ้งยอดทางอีเมลตามคำสั่งในรุ่นนี้

## v0.13.53 — หมวดคอร์สออนไลน์หน้าบ้านและหลังบ้าน

- เพิ่มปุ่มหมวด “คอร์สออนไลน์” ในแถบหมวดหน้าร้าน เชื่อมไปหน้าขายคอร์สโดยตรง
- การ์ดคอร์สออนไลน์บนหน้าแรกเปิดหน้าคอร์สจริง ไม่เลื่อนไปส่วนข้อความเดิม
- เพิ่มปุ่มคอร์สออนไลน์ในหน้าจัดการหมวดหมู่หลังบ้าน เชื่อมไปหน้าจัดการคอร์ส
- ใช้ระบบคอร์สเดิมร่วมกัน ไม่สร้างหมวดสินค้าดิจิทัลซ้ำหรือทำให้ข้อมูลคอร์สแยกเป็นสองชุด

## v0.13.52 — แบ่งหน้าจัดการสินค้า

- หน้าจัดการสินค้าแสดงครั้งละ 10 ตะกร้า เพื่อลดความช้าเมื่อสินค้ามีจำนวนมาก
- เพิ่มปุ่มก่อนหน้า เลขหน้า และถัดไป พร้อมแสดงหน้าปัจจุบัน
- การค้นหายังค้นจากสินค้าทั้งหมด แล้วแบ่งผลลัพธ์หน้าละ 10 รายการ
- การเลือกตะกร้าเพื่อลบยังคงจำรายการที่เลือกไว้เมื่อเปลี่ยนหน้า

## v0.13.51 — รวมไฟล์เนื้อหาน้อยและกรอกตะกร้าเอง

- เพิ่มช่องติ๊กเลือกไฟล์ในรายการรอรวม และรวมหลายไฟล์เป็น PDF เดียว
- สร้างรูปตัวอย่างจากแต่ละไฟล์ 1–3 รูปตามจำนวนหน้าที่มี และบังคับเลือกให้ครบ 3 รูป
- เพิ่มฟอร์มกรอกชื่อ หมวด ราคา จำนวนหน้า คำอธิบาย และรายละเอียดใน Vision 4
- เมื่อกรอกเองครบแล้ว ระบบสร้างสินค้าเปิดขายทันทีโดยไม่เข้าคิวรอ Boss ตรวจ
- ไฟล์ต้นฉบับจะออกจากรายการรอรวมเมื่อสร้างสินค้าและอัปโหลด PDF รวมสำเร็จเท่านั้น

## v0.13.50 — แก้หลังบ้านค้างไม่ตอบสนอง

- หยุดลูปตัวเฝ้าดู Vision 4 ที่เปลี่ยนข้อความปุ่มซ้ำอย่างต่อเนื่อง
- หน้าเมนูหลังบ้านและหน้าโปรโมชั่นกลับมาตอบสนองตามปกติ
- คงรายการโปรโมชั่นเฉพาะหมวดหลักจริงและตัดหมวดไดโนเสาร์เก่าออก

## v0.13.49 — หมวดโปรโมชั่นตรงกับสินค้าจริง

- รายการหมวดโปรโมชั่นใช้ชุดเดียวกับหมวดที่เลือกได้ในหน้าเพิ่มสินค้า
- ตัดหมวดเก่าและหมวดระบบออกจากตัวเลือกโปรโมชั่น
- ไม่แสดงหมวดเริ่มต้นเก่า เช่น ไดโนเสาร์ ตุ๊กตากระดาษ และเอกสาร
- แสดงเฉพาะหมวดหลักและจำนวนสินค้าในแต่ละหมวด ไม่แสดงหมวดย่อย

## v0.13.48 — ปุ่มโปรโมชั่นบนเมนูหลังบ้าน

- เพิ่มปุ่ม “โปรโมชั่น” บนแถบเมนูหลักของหลังบ้าน
- ย้ายหน้าตั้งค่าส่วนลดออกจากหน้าตั้งค่าชำระเงิน เพื่อให้ค้นหาและเปิดใช้งานได้ทันที
- ตั้งค่าเปิด/ปิด เลือกทุกหมวดหรือหมวดเดียว และกำหนดส่วนลด 1–90% ได้เหมือนเดิม

## v0.13.47 — แสดงรายละเอียดตรวจทันทีและรับ 30 ไฟล์

- การ์ดรอ Boss ตรวจแสดงข้อมูลการกรอกตะกร้าทั้งหมดทันที ไม่ต้องกดเปิดรายละเอียด
- การ์ดรอรวมชุดแสดงชื่อ ประเภท จำนวนหน้า ขนาด และสถานะทันที
- ปุ่มเปิดมีไว้ดูรูปตัวอย่างหรือเปิดไฟล์ต้นฉบับเท่านั้น
- เพิ่มจำนวนไฟล์เริ่มงาน Vision 4 จาก 10 เป็นสูงสุด 30 ไฟล์ต่อรอบ

## v0.13.46 — เปิดดูตะกร้าร่างในคิว Vision 4

- เพิ่มปุ่ม “ดูตะกร้าร่าง” ในรายการรอ Boss ตรวจ
- ดูรูปตัวอย่าง ชื่อ หมวด ประเภทไฟล์ จำนวนหน้า ราคา คำอธิบาย และรายละเอียดได้โดยไม่ออกจาก Vision 4
- มีปุ่มเปิดไฟล์ต้นฉบับก่อนตัดสินใจตรวจผ่าน

## เริ่มใช้งาน
1. ติดตั้ง Node.js
2. `npm install`
3. ล็อกอิน Cloudflare: `npx wrangler login`
4. สร้าง D1: `npx wrangler d1 create visiond-db`
5. นำ database_id ใส่ใน `wrangler.toml`
6. สร้าง R2 bucket ชื่อ `visiond-files`
7. รัน migration: `npm run db:init`
8. รันในเครื่อง: `npm run dev`

## VisionD v0.4 — ตั้งค่า Boss
หลังเชื่อม D1 และรัน migrations ให้สมัครบัญชีเจ้าของระบบก่อน แล้วรัน SQL ใน D1 Console:

```sql
UPDATE users SET role='boss' WHERE lower(email)=lower('อีเมลเจ้าของระบบ');
```

ระดับสมาชิก:
- `boss` เจ้าของระบบ สิทธิ์สูงสุดและเปลี่ยน User เป็น Admin ได้
- `admin` ตรวจสลิป อนุมัติออเดอร์ และเข้าหลังบ้าน
- `user` บัญชีลูกค้าที่สมัครผ่านหน้าเว็บ

ห้ามเปิดให้ผู้สมัครเลือกระดับ Boss/Admin เอง หน้า Register จะสร้างเป็น User เท่านั้น
