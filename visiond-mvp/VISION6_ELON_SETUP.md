# Vision 6 — ELON AI Support

ELON เป็นผู้ช่วยสำหรับสมาชิก VisionD และตอบเฉพาะเรื่องเว็บไซต์ VisionD ได้แก่ สินค้าดิจิทัล คอร์ส คำสั่งซื้อ สลิป สิทธิ์ดาวน์โหลด เครดิตตะกร้าคอร์ส Vision 4, Vision 5 และการใช้งานบัญชี

## ตั้งค่า Cloudflare Pages

1. เปิดโปรเจกต์ VisionD ใน Cloudflare Dashboard
2. ไปที่ Settings → Variables and Secrets
3. เพิ่ม Secret ชื่อ `OPENAI_API_KEY` แล้ววาง API key ของบัญชีที่บริษัทใช้
4. เพิ่มตัวแปร `OPENAI_MODEL` หากต้องการเปลี่ยนโมเดล ค่าเริ่มต้นในระบบคือ `gpt-4.1-mini`
5. Deploy ZIP นี้ตามขั้นตอนเดิม

ห้ามใส่ `OPENAI_API_KEY` ลงใน JavaScript, HTML, Git หรือไฟล์ ZIP โดยตรง

## ขอบเขตความปลอดภัย

- ELON แสดงเฉพาะสมาชิกที่เข้าสู่ระบบ
- สมาชิกอ่านได้เฉพาะบทสนทนาของบัญชีตัวเอง
- Boss อ่านและค้นหาบทสนทนาทั้งหมดได้จาก Control Center
- ระบบเก็บบทสนทนาและข้อความย้อนหลัง 60 วัน (2 เดือน) แล้วลบอัตโนมัติ
- ELON ไม่มีสิทธิ์อนุมัติสลิป เพิ่มเครดิต เปลี่ยน Role หรือแก้ข้อมูลบัญชี
- คำถามนอกบริบท VisionD จะถูกปฏิเสธและแนะนำให้ถามเฉพาะเรื่องเว็บไซต์
- ELON ไม่เปิด วิเคราะห์ หรือตอบกลับด้วยลิงก์ภายนอก อนุญาตเฉพาะเส้นทางภายใน VisionD, `developer.easyslip.com` สำหรับแนะนำการสมัคร API และ `api.easyslip.com` ที่ Vision 5 ใช้ตรวจสลิป
- แม้เป็นโดเมน EasySlip ที่อนุญาต ELON มีสิทธิ์เพียงแนะนำหรืออธิบายการตั้งค่า ไม่เรียก API แทนและไม่รับหรือแสดง Token
- ปุ่มส่งต่อเจ้าหน้าที่ของ ELON พาไปหน้า `/contact.html` ภายใน VisionD เท่านั้น
- API key ถูกเรียกใช้ฝั่ง Cloudflare Function เท่านั้น

## การทดสอบหลัง Deploy

1. ล็อกอินด้วยบัญชี User แล้วตรวจว่าปุ่ม “ถาม ELON AI” ปรากฏ
2. ถาม “ซื้อสินค้าอย่างไร” และตรวจว่าตอบเกี่ยวกับ VisionD
3. ถามเรื่องนอกเว็บไซต์ เช่น ข่าวหรือการเมือง และตรวจว่า ELON ปฏิเสธ
4. ส่งลิงก์เว็บไซต์ภายนอกและตรวจว่า ELON ปฏิเสธโดยไม่ส่งลิงก์นั้นไปยัง AI
5. เปิด Dashboard/หน้าสินค้า/หน้าคอร์ส แล้วตรวจว่าคำถามด่วนเปลี่ยนตามหน้า
6. ล็อกอิน Boss เปิดหลังบ้าน → เพิ่มเติม → ELON AI และตรวจรายการสนทนา
7. ล็อกอิน User คนอื่นและยืนยันว่าเปิดบทสนทนาของผู้อื่นไม่ได้
8. ตรวจหน้าหลังบ้านว่าระบุระยะเวลาเก็บประวัติ 60 วัน
