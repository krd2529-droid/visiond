# PATCH v0.14.312 — Paper Doll PDF Sets

- เพิ่มปุ่ม `สร้างตะกร้าตุ๊กตากระดาษ` ในหน้าการจัดการสินค้า
- อ่าน PDF แต่ละไฟล์เป็นคนละกลุ่ม และแบ่งหน้าของทุกกลุ่มให้ครบทุกตะกร้าตามลำดับ
- กระจายเศษหน้าให้ตะกร้าแรกทีละหน้าโดยไม่มีหน้าซ้ำหรือตกหล่น
- แสดง Preview ช่วงหน้า รูปปก จำนวนหน้ารวม และราคา ก่อนสร้างจริง
- รองรับราคาเดียวและราคาแยกแต่ละตะกร้า
- สร้างเป็นร่างหมวด `paper-doll` ชื่ออัตโนมัติ และ Slug `paper-doll-set-NNN`
- หากงานกลางชุดล้ม สามารถทำต่อจากตะกร้าที่ค้างโดยไม่สร้างใบที่สำเร็จแล้วซ้ำ
