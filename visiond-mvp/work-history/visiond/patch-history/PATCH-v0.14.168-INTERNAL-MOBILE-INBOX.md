# Patch v0.14.168 — Internal Mobile Inbox

V Easy v1.0.22 no longer replaces its WebView with the desktop LINE Official Account Manager. The owner can open a responsive internal inbox, inspect LINE history, take over one conversation, send a reply through the server, return it to the bot, and explicitly return to the V Easy chat page.

LINE participant identifiers remain encrypted on the server. The inbox API requires the signed-in Vision7 owner and never returns channel credentials or the encrypted delivery target.
