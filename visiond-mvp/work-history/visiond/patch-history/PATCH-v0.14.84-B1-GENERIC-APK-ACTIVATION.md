# VisionD v0.14.84 — B1 Generic APK Activation

- การออกคีย์กับการเผยแพร่ APK แยกเป็นคนละขั้นตอนและคนละส่วน UI
- APK ไม่มีคีย์หรือบัญชีลูกค้าฝังอยู่ ลูกค้าทุกคนติดตั้งไฟล์เดียวกัน
- V Easy 1.0.8 รับ ID, Password และ V Easy Key ภายใน Settings
- ตรวจว่าคีย์เป็นประเภท V Easy และเป็นของบัญชีที่ล็อกอิน
- คีย์ที่ยังไม่ผูกร้านจะสร้างร้านครั้งแรกและเปลี่ยนเป็น bound
- คีย์ที่ผูกแล้วกลับเข้าได้เฉพาะร้านเดิม
- จำกัดจำนวนเครื่องตาม License และยกเลิกเครื่องปัจจุบันได้ในแอป
- Session เดิมยังคงอยู่เมื่ออัปเดต APK จึงไม่ต้องออกคีย์ใหม่

ชุดส่งมอบ: VisionD v0.14.84 + V Easy Source v1.0.8 + APK v1.0.8
