# VisionD v0.14.88 — Admin Large Menu

## Event Case

- ยกเลิกเมนู “เพิ่มเติม” แบบพับได้
- แสดงเมนูหลังบ้านทุกส่วนเป็นการ์ดปุ่มใหญ่แบบเดียวกับ Vision 4
- จอใหญ่เรียง 4 คอลัมน์ และมือถือเรียง 2 คอลัมน์โดยยังคงปุ่มขนาดใหญ่
- แสดงสถานะเมนูที่เลือกอย่างชัดเจน
- แยกถังขยะเป็นการ์ดสีแดงและคงสิทธิ์ Boss-only
