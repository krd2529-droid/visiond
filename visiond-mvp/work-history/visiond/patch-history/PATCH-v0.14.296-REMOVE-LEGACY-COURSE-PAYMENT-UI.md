# v0.14.296 — ลบหน้าเก่าบัญชีผู้สร้างคอร์ส

- ลบกล่องบัญชีรับเงินของเจ้าของคอร์สออกจาก HTML ไม่ใช้การซ่อน
- ลบกล่องตั้ง EasySlip ของผู้สอนและ JavaScript ที่ผูกกับฟอร์มเก่า
- ระบบพาร์ตเนอร์ใช้ VisionD รับเงิน ตรวจสลิป และแบ่งรายได้ตามเงื่อนไขปัจจุบัน
- เปลี่ยนข้อความปุ่มขั้นแรกเป็น “บันทึกข้อมูลและไปจัดการ EP” เพื่อไม่สับสนกับปุ่มสร้างคอร์สเดิม
- ร่างเดิมยังถูกคืนจาก API และเข้าสู่ส่วน EP/ส่งตรวจตามแพตก่อนหน้า
