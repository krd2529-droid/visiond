# v0.14.293 — แดชบอร์ดยอดขายคอร์ส

- เพิ่มยอดขายรวม รายได้ส่วนผู้สอน จำนวนออเดอร์ และจำนวนสมาชิกที่ซื้อ
- เลือกวันเริ่มต้นและสิ้นสุดย้อนหลังได้ครั้งละไม่เกิน 60 วัน
- แสดงชื่อสมาชิก คอร์ส ยอดขายส่วนรวม รายได้ผู้สอน และวันเวลา
- แสดงตะกร้าคอร์สเก่าและใหม่ของเจ้าของรวมกัน กดเข้าแก้ไขและส่งตรวจซ้ำได้
- API จำกัดข้อมูลด้วยเจ้าของคอร์สจาก session และไม่คืนข้อมูลติดต่อสมาชิก
