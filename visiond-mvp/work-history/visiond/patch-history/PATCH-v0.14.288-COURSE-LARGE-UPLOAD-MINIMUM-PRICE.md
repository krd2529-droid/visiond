# PATCH v0.14.288 — อัปโหลดวิดีโอคอร์สไฟล์ใหญ่และราคาขั้นต่ำ

- เปลี่ยนหน้าเจ้าของคอร์สให้อัปโหลดวิดีโอแบบ multipart ครั้งละ 25 MB สูงสุด 2 GB
- ระบุไฟล์ต้นฉบับ 720p หรือ 480p เพื่อลดต้นทุนพื้นที่และการส่งข้อมูล
- หากอัปโหลดวิดีโอล้มเหลว ข้อมูล EP ยังคงเป็นร่างและอัปโหลดซ้ำได้
- กำหนดราคาคอร์สขั้นต่ำ 499 บาทในฟอร์มสร้าง ฟอร์มส่งตรวจ และ API ทุกจุด
- ไม่ทำ transcoding หรือแบ่งเนื้อหาวิดีโออัตโนมัติ เพราะอาจตัดเนื้อหาผิดช่วงโดยไม่มีระบบประมวลผลสื่อเฉพาะ
