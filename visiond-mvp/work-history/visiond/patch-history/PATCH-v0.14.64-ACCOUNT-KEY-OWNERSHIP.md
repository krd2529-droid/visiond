# PATCH v0.14.64 — Account + Key Ownership

## ทำแล้ว

- เพิ่มการล็อกอินของโปรแกรมด้วยไอดีหรืออีเมลและรหัสผ่าน VisionD

- ล็อกอินใหม่บนเครื่องเดิมจะยกเลิก Session เก่า ป้องกัน Session ซ้อนค้าง
- เพิ่มตรวจ Session, ออกจากระบบ และตรวจบัญชีปัจจุบัน
- Activation, รายการโปรแกรม และดาวน์โหลด Release ตรวจเจ้าของด้วย VisionD Session
- คีย์ของบัญชีอื่นไม่สามารถเปิดใช้งานกับบัญชีที่ล็อกอินอยู่ได้
