# v0.14.295 — คืนร่างล่าสุดและเอาปุ่มสร้างคอร์สเก่าออก

- แก้ร่างที่สร้างก่อนระบบจำ `course_id` ซึ่งทำให้รีเฟรชแล้วกลับไปเห็นปุ่มสร้างร่างคอร์ส
- หาก URL และแท็บไม่มีรหัส ระบบจะค้นหาร่างล่าสุดที่ยังแก้ไขหรือส่งตรวจได้ของเจ้าของ
- คืนรหัสร่างลง URL เปิดส่วน EP และแสดงขั้นตอนส่งตรวจโดยอัตโนมัติ
- ไม่สร้างร่างซ้ำ ไม่ลบ และไม่ซ่อนข้อมูลเดิม
