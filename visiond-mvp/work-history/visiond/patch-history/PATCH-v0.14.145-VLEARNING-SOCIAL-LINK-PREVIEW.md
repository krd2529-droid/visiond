# v0.14.145 — V-Learning social link preview

- พรีวิวลิงก์หน้าแรกบน Facebook, LINE, Messenger และบริการที่รองรับ Open Graph ดัน V-Learning เป็นบริการหลัก
- เปลี่ยน Open Graph และ Twitter Card เป็นภาพ V-Learning ที่อนุมัติ ผ่าน HTTPS URL แบบเต็ม
- ชื่อและคำอธิบายเน้นระบบคอร์สออนไลน์ จ่ายครั้งเดียว และรับยอดขายเต็มไม่หักเปอร์เซ็นต์
- ระบุชนิดไฟล์ ขนาดภาพ ข้อความทดแทน และ site name ให้ตัวอ่านพรีวิวตีความได้ชัดเจน
- ไม่แก้ metadata ของหน้าสินค้าหรือหน้าคอร์สเฉพาะรายการ
