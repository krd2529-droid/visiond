# PATCH v0.14.65 — V Easy Shop Binding

## ทำแล้ว

- เพิ่มร้าน V Easy ที่มีเจ้าของบัญชี คีย์ และ Facebook Page ID ชัดเจน
- บังคับฐานข้อมูล `1 license_id = 1 shop`
- บังคับฐานข้อมูล `1 Meta Page ID = 1 shop`
- ผูกคีย์ได้เฉพาะ Session ของเจ้าของคีย์และเฉพาะโปรแกรมประเภท V Easy
- ผูกซ้ำข้อมูลเดิมได้แบบ idempotent แต่ห้ามนำคีย์ไปผูกร้านที่สอง
- เปลี่ยนสถานะคีย์จาก `unbound` เป็น `bound` ใน D1 batch เดียวกับการสร้างร้าน
- API รายการร้านคืนเฉพาะร้านของบัญชี Session ปัจจุบัน

## ขอบเขตการยืนยัน Facebook Page

แพตนี้ยืนยันความเป็นเจ้าของภายในระบบจากบัญชีที่ล็อกอินและล็อก Page ID ไม่ให้ซ้ำ การตรวจสิทธิ์จัดการเพจจริงกับ Meta จะทำตอนเชื่อม OAuth/Page Token ของโปรแกรม V Easy
