# v0.14.108 — VBot Marketplace Foundation

วางฐานสร้างแอป VBot จากฟอร์มเดียวโดยไม่เสียเครดิตหรือซื้อสิทธิ์สร้าง: ชื่อ รายละเอียด ปก ไฟล์ติดตั้ง แพลตฟอร์ม เวอร์ชัน และราคาแพ็กเกจ 30 วัน/1 ปี/ตลอดชีพ

ราคาขายคีย์เป็น `vision7_plans.offer_price` หน่วยสตางค์ที่เว้นว่างเป็น `NULL` ได้ เพื่อแยก “ร่างที่ยังไม่เปิดขาย” ออกจากราคา 0 บาท ราคาลูกค้าต้องมากกว่า 0 และไม่เปลี่ยนความหมายของ `vision7_plans.price` เดิม ระบบยังใช้ Program, Plan, Release และ License ของ Vision 7 ชุดเดียว

เซิร์ฟเวอร์รับ multipart ที่ endpoint โปรแกรมเดิม ตรวจชนิด/ขนาดปกและตัวติดตั้ง สร้าง release แรกพร้อม SHA-256 และล้างทั้ง record กับไฟล์ R2 หากงานช่วงใดล้มเหลว

ตัวติดตั้งแอปดาวน์โหลดฟรีจากรหัสแอป ส่วนลูกค้าชำระเงินเพื่อซื้อคีย์ใช้งาน กฎ 1 คีย์ = 1 ร้านจำกัดเฉพาะแพลตฟอร์ม V Easy; VBot Android และแพลตฟอร์มอื่นไม่รับกฎนี้โดยปริยาย
