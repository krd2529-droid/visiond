# VisionD v0.14.51 — Vision 7 + ELON Page Foundation

วันที่: 2026-08-10

## สิ่งที่ทำในแพตนี้

- เพิ่มฐานข้อมูลโปรแกรม แพ็กเกจ คีย์ อุปกรณ์ สิทธิ์ทดลอง และประวัติการใช้งานของ Vision 7
- กำหนด 1 คีย์ใช้พร้อมกันได้ 3 เครื่อง ผูกคีย์กับบัญชี VisionD และให้ลูกค้าปิดเครื่องเก่าเองได้ทันที
- รองรับตลอดชีพ รายเดือน รายปี การหมดอายุ การระงับ และการบังคับอัปเดต
- รองรับทดลอง 24 ชั่วโมง 1 สิทธิ์ต่อบัญชีต่อโปรแกรม เริ่มนับเมื่อเริ่มใช้
- เพิ่มหน้า `โปรแกรมของฉัน` และหน้าควบคุม Vision 7 แยก
- เพิ่มพื้นที่ข้อมูล ELON Page นักขาย แยกจาก ELON สมาชิก พร้อมคิวส่งต่อให้คนและเก็บข้อมูล 60 วัน
- เพิ่ม `ศูนย์โฆษณา` แยกจากแดชบอร์ดรายได้เดิม วิเคราะห์ ROAS/กำไรและให้คำแนะนำโดยไม่แก้แอดอัตโนมัติ

## ความปลอดภัย

- ไม่เก็บ license key แบบอ่านได้ เก็บ SHA-256 และแสดงเฉพาะท้าย 4 ตัว
- การเปิดใช้ต้องล็อกอินด้วยบัญชีเจ้าของคีย์
- device ID ถูก hash ก่อนบันทึก
- หน้าและ API ผู้ดูแลตรวจ role ทุกครั้ง

## งานที่ต้องแพตต่อ

1. เชื่อมคำสั่งซื้อ Vision 7 กับการออก/ต่ออายุคีย์อัตโนมัติและ quantity หลายคีย์
2. ทำ Meta Messenger webhook จริง: ตรวจ signature, dedupe, token encryption และข้อกำหนดหน้าต่าง 24 ชั่วโมง
3. เชื่อม ELON `PAGE_SALES` กับข้อมูลสินค้า/ราคา/นโยบายที่ตรวจสอบแล้ว พร้อมคำตอบและลิงก์ภายใน
4. ทำหน้าฟอร์มออกคีย์/ต่ออายุ/ประวัติแบบเต็ม และระบบดาวน์โหลดไฟล์โปรแกรม/บังคับอัปเดต
5. เชื่อม Ads API/ข้อมูลระดับ campaign-adset-creative จริงและเพิ่มเกณฑ์แนะนำจากข้อมูล production

EVENT CASE: ยังไม่เสร็จ — ต้องแพตต่อ
