# v0.14.287 — Course Center Single Partner Plan

## เป้าหมาย

ลดศูนย์จัดการคอร์สให้เหลือรูปแบบสร้างใหม่แบบเดียว คือพาร์ตเนอร์ 50/50 โดยไม่ทำลายคอร์สซื้อสิทธิ์เดิม

## การเปลี่ยนแปลง

- UI Course Center แสดงปุ่มสร้างคอร์สพาร์ตเนอร์เพียงปุ่มเดียว
- URL เดิม `type=1` และ `type=2` เข้าหน้าพาร์ตเนอร์เดียวกัน
- API ปฏิเสธการสร้างแผนอื่นด้วย `COURSE_PLAN_CLOSED`
- ลบ branch หักเครดิตจาก API สร้างใหม่จริง ไม่ใช้วิธีซ่อน
- คอร์ส rights/free เดิมยังคำนวณรายได้และจัดการย้อนหลังด้วย legacy compatibility

## ข้อควรระวัง

- `course_origin='seller_rights'` ยังเก็บไว้เป็นชนิดตะกร้าจากผู้ขาย เพราะระบบตรวจคอร์สและไฟล์เดิมใช้ค่านี้ร่วมกัน; ความต่างด้านรายได้ใช้ `course_plan`
- ห้ามลบข้อมูลเครดิตหรือคอร์สเดิมจากฐานข้อมูลในแพตนี้

## Rollback

ใช้ `git revert SELF` เท่านั้น แล้วตรวจ `SAFE-BASELINE.md` และรันทดสอบครบก่อนเผยแพร่
