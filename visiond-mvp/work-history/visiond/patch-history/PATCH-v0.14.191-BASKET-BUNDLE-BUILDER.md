# VisionD v0.14.191 — Basket Bundle Builder

เพิ่มปุ่ม `สร้างชุดรวมตะกร้า` ในหน้าจัดการสินค้า ถัดจากปุ่มเพิ่มสินค้าเอง พร้อมสรุปราคาปกติรวม จำนวนหน้ารวม จำนวนตะกร้า ราคาชุดโปร และส่วนลดแบบทันที

ผู้ดูแลปรับจำนวนตะกร้า 2–30 รายการและจำนวนรูปตัวอย่างจากรูปปกแรกได้ รายการต้นทางเรียงจากเลขตะกร้าเก่าไปใหม่ รายละเอียดเริ่มต้นเก็บรายชื่อ ราคา และจำนวนหน้าตามลำดับ

เพิ่ม `bundle_source_allocations` เพื่อกันตะกร้าเดี่ยวที่เคยถูกรวมแล้วกลับมาใช้ในชุดใหม่ ทั้งหน้า UI และ API โดยยังแก้ไขชุดเดิมได้
