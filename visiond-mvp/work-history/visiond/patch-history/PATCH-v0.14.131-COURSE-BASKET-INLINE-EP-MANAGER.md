# Patch v0.14.131 — Course Basket Inline EP Manager

วันที่: 2026-08-11

## ผลลัพธ์

- รวมตัวจัดการ EP ไว้ในหน้าแก้ไขตะกร้าคอร์สใบเดียวกัน
- เปลี่ยน label `ชื่อตะกร้าคอร์ส` เป็น `ชื่อคอร์ส`
- เพิ่ม สร้าง แก้ไข ลบ EP และลบไฟล์ประกอบได้จากหน้านี้
- ใช้ API เจ้าของคอร์สเดิม ไม่สร้างข้อมูล EP ชุดซ้ำ
- คงกฎล็อกเนื้อหาหลังมีออเดอร์หรือหมดระยะเวลาแก้ไข
- บันทึกข้อมูลตะกร้าแล้วอยู่หน้าเดิม เพื่อทำ EP ต่อได้ทันที

## ขอบเขตความปลอดภัย

- เจ้าของต้องผ่าน session และเป็นเจ้าของตะกร้า
- หลังมีผู้ซื้อแล้ว API ปฏิเสธการเปลี่ยนเนื้อหา EP
- ไฟล์วิดีโอและไฟล์ประกอบยังใช้ข้อจำกัดชนิด/ขนาดเดิม
