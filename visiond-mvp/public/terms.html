ข้อกำหนดการใช้งาน

ข้อกำหนดนี้ใช้กับการสมัครบัญชีและการใช้เว็บไซต์ VisionD Online โปรดอ่านก่อนสมัครหรือใช้บริการ

บัญชีผู้ใช้

  • ผู้ใช้ต้องให้ข้อมูลที่ถูกต้องและดูแลรหัสผ่านของตน
  • ห้ามใช้บัญชีเพื่อเข้าถึงระบบหรือข้อมูลของผู้อื่นโดยไม่ได้รับอนุญาต
  • หากสงสัยว่าบัญชีถูกใช้โดยผู้อื่น กรุณาเปลี่ยนรหัสผ่านและติดต่อ VisionD

การสั่งซื้อและเนื้อหาดิจิทัล

ราคา รายละเอียดสินค้า วิธีชำระเงิน และสิทธิ์ใช้งานเป็นไปตามข้อมูลที่แสดงในหน้าสินค้าหรือคอร์สนั้น การเข้าถึงอาจเริ่มหลังตรวจสอบการชำระเงินสำเร็จ

การใช้งานที่ไม่อนุญาต

ห้ามรบกวนความปลอดภัยของระบบ ส่งคำขออัตโนมัติที่เกินสมควร เผยแพร่เนื้อหาที่ผิดกฎหมาย หรือละเมิดสิทธิของผู้อื่น VisionD อาจจำกัดการใช้งานที่สร้างความเสียหายต่อระบบหรือผู้ใช้รายอื่น

การใช้ V Easy และระบบอัตโนมัติ

  • เจ้าของร้านต้องมีสิทธิ์ดูแล LINE Official Account, Facebook Page หรือบัญชีภายนอกที่นำมาเชื่อม
  • เจ้าของร้านรับผิดชอบสินค้า ราคา สต็อก เงื่อนไขขาย การจัดส่ง ภาษี การคืนเงิน และข้อความที่ส่งจากร้าน
  • AI เป็นเครื่องมือช่วยและอาจผิดพลาด เจ้าของร้านต้องตรวจเรื่องสำคัญและรับช่วงเมื่อระบบแจ้งเตือน
  • คำสั่งซื้อเก็บเงินปลายทางและกรณีนอกขอบเขตต้องได้รับการอนุมัติตามขั้นตอนของร้าน

กฎของแพลตฟอร์มภายนอก

การเชื่อม LINE, Facebook หรือบริการอื่นต้องใช้ API, Webhook, OAuth, Token และสิทธิ์ที่แพลตฟอร์มอนุญาตเท่านั้น ผู้ใช้ต้องปฏิบัติตามข้อกำหนด นโยบายข้อมูล โควตาข้อความ การตรวจสอบแอป และข้อจำกัดของแต่ละแพลตฟอร์ม

  • ห้ามใช้รหัสผ่านส่วนบุคคล คุกกี้ เซสชัน การดัก Token หรือโปรแกรมกดหน้าจอเพื่ออ่านข้อความหรือส่งข้อความแทน API ทางการ
  • ห้ามส่งสแปม หลอกลวง ปลอมตัว รบกวนผู้ใช้ หรือส่งโฆษณาโดยไม่มีฐานสิทธิและความยินยอมที่เหมาะสม
  • ห้ามรวมข้อมูลผู้ใช้ข้ามร้าน ข้าม Provider หรือข้ามแพลตฟอร์มเพื่อสร้างโปรไฟล์โดยไม่ได้รับอนุญาต
  • ห้ามเปิดเผย Channel Secret, Access Token, App Secret หรือข้อมูลรับรอง หากสงสัยว่ารั่วต้องเพิกถอนและออกใหม่ทันที

หากแพลตฟอร์มระงับ Token, Webhook, Page, Channel หรือสิทธิ์ API จากเหตุที่อยู่นอกการควบคุมของ VisionD บริการส่วนนั้นอาจหยุดทำงานจนกว่าเจ้าของบัญชีจะแก้ไขกับแพลตฟอร์มต้นทาง

การยุติการเชื่อมต่อ

เจ้าของร้านสามารถหยุดบอทหรือขอยกเลิกการเชื่อมต่อได้ และควรปิด Use webhook พร้อมเพิกถอน Token ใน LINE Developers Console หรือ Meta for Developers เมื่อเลิกใช้ถาวร การยกเลิกไม่ลบประวัติคำสั่งซื้อหรือหลักฐานที่จำเป็นโดยอัตโนมัติ

การเปลี่ยนแปลงบริการ

รายละเอียดบริการอาจเปลี่ยนเพื่อแก้ข้อผิดพลาด เพิ่มความปลอดภัย หรือปรับการทำงาน การเปลี่ยนแปลงข้อกำหนดที่มีสาระสำคัญจะระบุเวอร์ชันและวันที่บนหน้านี้

ติดต่อ

หากมีคำถามเกี่ยวกับข้อกำหนด กรุณาใช้ช่องทางในหน้า ติดต่อเรา อ่านการจัดการข้อมูลส่วนบุคคลได้ใน นโยบายความเป็นส่วนตัว
