ติดตั้ง Helper ด้วยตนเอง

ทำในเบราว์เซอร์นี้ได้ตั้งแต่ดาวน์โหลดจนยืนยันเครื่อง ไม่ต้องให้ผู้ดูแลส่งไฟล์ให้ เว็บไซต์จะไม่ติดตั้งโปรแกรมให้อัตโนมัติ

1. ดาวน์โหลดลงเครื่อง Windows นี้

ตัวติดตั้งปัจจุบัน 0.20.78 · Windows x64 · .NET Framework 4.8 · Chrome
เว็บไซต์ v0.20.109 ใช้ตัวติดตั้ง v0.20.78 ที่ผ่านการตรวจแล้ว

ดาวน์โหลด Helper สำหรับ Windows

กำลังตรวจข้อมูลไฟล์ก่อนเปิดปุ่มดาวน์โหลด…

รุ่นนี้ยังไม่มีลายเซ็นดิจิทัลผู้เผยแพร่ Windows อาจเตือนหรือปิดกั้น

ตรวจ SHA256 และซอร์สของไฟล์

ข้อมูลรุ่นและ SHA256 · ดาวน์โหลดซอร์สรุ่นนี้

2. เปิดไฟล์และติดตั้งด้วยตนเอง

  1. กดปุ่มดาวน์โหลดด้านบน แล้วเปิดรายการดาวน์โหลดของเบราว์เซอร์ หา VisionD-Helper-Setup-0.20.78.exe
  2. เปิดไฟล์ / Run และอ่านคำเตือนของ Windows ตรวจว่าเป็นไฟล์จาก VisionD ที่เพิ่งดาวน์โหลด หากนโยบายองค์กรปิดกั้นให้หยุดและติดต่อผู้ดูแล ไม่ต้องปิดระบบความปลอดภัย
  3. ในหน้าต่าง Helper เลือก ติดตั้ง / อัปเดตตัวช่วย และยืนยัน จากนั้นอ่านผลในหน้าต่างนั้น การดาวน์โหลดอย่างเดียวยังไม่ใช่การติดตั้ง
  4. ถ้ารายงาน ติดตั้งและตรวจตัวช่วยแล้ว กลับหน้านี้เพื่อผูกเครื่องเฉพาะเมื่อยังไม่เคยผูก ถ้ารายงานพอร์ตเดิมถูกใช้งาน ให้เลือกขั้นตอนซ่อมด้านล่าง อย่ากด Connect ซ้ำแทนการติดตั้ง

3. เลือกสถานการณ์ของคุณ

เว็บไซต์ไม่ได้ตรวจพบโปรแกรมในเครื่องโดยอัตโนมัติ สถานะต่อไปนี้เป็นสิ่งที่คุณเลือกเอง การพบ Helper ในบัญชีไม่ยืนยันว่าโปรแกรมกำลังทำงาน

เริ่มจากดาวน์โหลดด้านบน เปิดไฟล์และเลือกติดตั้ง จากนั้นอ่านผลในหน้าต่าง Helper

4. ผูกเครื่องหรือยืนยันรหัสซ่อมในหน้าเดิม

เฉพาะเครื่องที่ยังไม่ผูก หรือกำลังซ่อมตามผลจาก Helper เท่านั้น ถ้าเครื่องผูกและทำงานแล้ว ไม่ต้องผูกซ้ำ

กำลังตรวจบัญชี VisionD…

เปิด Helper ที่ติดตั้งแล้วเพื่อรับรหัส

ปุ่มเปิด Helper ไม่ใช่ปุ่มติดตั้ง หาก Windows ไม่เปิดให้ ให้เปิดไฟล์ Helper ที่ตรวจสอบแล้วด้วยตนเอง แล้วเลือกผูกเครื่อง หรือเลือกซ่อมพอร์ตตามผลที่เห็น ตัวช่วยไม่เปิด Edge หรือเว็บไซต์ใหม่

รหัสซ่อมต้องยืนยันด้วยบัญชีเดิมและแทน Helper เดิมให้ตรงกัน ก่อนยืนยันข้อมูลเดิมยังคงอยู่ หลังยืนยันรอ Helper ตรวจพอร์ตใหม่ หากยังไม่พร้อมให้อ่านข้อผิดพลาดและกดซ่อมเพื่อดำเนินการต่อด้วยคำขอเดิม

กลับ Analyzer แล้วรีเฟรชสถานะช่อง

Helper ทุกรุ่นต่ำกว่า 0.20.78 ต้องดาวน์โหลดและติดตั้งอัปเดตก่อนเปิดช่อง เพื่อป้องกันหน้าต่างเริ่มต้น Chrome ส่วนเกิน การอัปเดตปกติรักษาโปรไฟล์และการผูกเดิม ไม่ต้องผูกซ้ำ

ความเป็นส่วนตัวและการถอนติดตั้ง

Helper ไม่คัดลอกคุกกี้ ไม่เปลี่ยนเบราว์เซอร์หลักหรือบัญชี TikTok และไม่อนุญาต API แทนคุณ การล็อกอินและยินยอม TikTok เป็นขั้นตอนที่คุณทำเองในโปรไฟล์ของช่อง

ถอนจากปุ่มใน Helper ได้ โดยเก็บ Profiles และข้อมูลการผูกเครื่อง หากเปิดจากตำแหน่งติดตั้ง ไฟล์ที่กำลังเปิดจะคงอยู่ ให้ปิดแล้วถอนผ่าน Setup ที่ดาวน์โหลดเมื่อต้องการลบไฟล์โปรแกรม
