เริ่ม Helper เพื่อรับรหัสผูกเครื่อง

ติดตั้งรุ่น 0.20.75 ก่อน หากกดแล้วไม่เปิด ให้เปิด Helper ที่ตรวจสอบแล้วด้วยตนเองและเลือกผูกเครื่อง ตัวช่วยจะแสดงรหัส ไม่เปิด Edge หรือเว็บไซต์ใหม่

  1. เปิดไฟล์ที่ดาวน์โหลด เลือก “ติดตั้ง / อัปเดตตัวช่วย” แล้วตรวจข้อความสำเร็จ
  2. กลับ Chrome หน้านี้ เข้าสู่ระบบด้วยบัญชีที่ใช้ช่องนี้ กดเริ่ม Helper และอนุญาตในหน้าต่างตัวช่วย
  3. กรอกรหัสใหม่จากตัวช่วยในหน้านี้ เทียบรหัส ติ๊กว่ารหัสตรงกัน แล้วกดยืนยันผูกเครื่อง
  4. กลับหน้า Analyzer แล้วกดเชื่อมช่องที่ต้องการ

หากใช้ Helper รุ่น 0.20.75 ขึ้นไป เปิดตัวช่วยแล้วเลือกผูกเครื่องได้ หากเป็นรุ่น 0.20.74 หรือต่ำกว่า หรือเปิดแล้วไม่มีหน้าติดตั้ง ให้ดาวน์โหลดรุ่นนี้และอัปเดตก่อน โปรไฟล์เดิมจะคงอยู่

กำลังอ่านข้อมูลรุ่นและลายเซ็น…

ข้อมูลรุ่นและ SHA256 · ซอร์สของรุ่นนี้

หาก Windows หรือนโยบายองค์กรปิดกั้นไฟล์ ให้หยุดและติดต่อผู้ดูแลหรือรอรุ่นที่ลงลายเซ็น ไม่ต้องปิดระบบความปลอดภัยของ Windows

ถอนตัวช่วยได้จากปุ่มใน Helper โดยเก็บโปรไฟล์และข้อมูลการผูกเครื่องไว้ หากเปิดจากตำแหน่งติดตั้ง ไฟล์ที่กำลังเปิดจะคงอยู่ ให้ปิดแล้วถอนผ่านไฟล์ Setup ที่ดาวน์โหลดหากต้องการลบไฟล์โปรแกรม การติดตั้งบนเครื่องอื่นต้องผูกเครื่องนั้นเอง
