ค้นสินค้า Open Collaboration ก่อนเพิ่มเข้า Showcase

หน้า Marketplace ของ VisionD ค้นจากรายการ Open Collaboration ของ TikTok ไม่ใช่ค้นเฉพาะสินค้าที่อยู่ใน Showcase เดิม คุณกรองด้วยชื่อสินค้า ร้านค้า หมวดหมู่ ราคา และค่าคอมได้

สินค้าขายดีและสินค้าใหม่

ยอดขายเรียงจากฟิลด์ units_sold ที่ TikTok ส่งมา ส่วนวันที่สินค้าใหม่จะแสดงเฉพาะเมื่อผล API มีเวลาเผยแพร่หรือเวลาสร้างที่เชื่อถือได้ หาก TikTok ไม่ส่งฟิลด์นี้ ระบบจะแสดงขีดแทนการคาดเดา

เพิ่มเข้า Showcase

เลือกสินค้าที่ต้องการแล้วกดเพิ่ม ระบบส่งครั้งละไม่เกิน 20 รหัสตามข้อกำหนด API และรายงานข้อผิดพลาดแยกแต่ละสินค้า การใช้งานต้องมีสิทธิ์ค้นหา Collaboration และสิทธิ์เขียน Showcase จากบัญชี Creator
