VISION 5 — โปรดอ่านก่อนซื้อสิทธิ์ลงขายคอร์ส
VisionD Online · v0.13.97
============================================================

1. ราคาและสิทธิ์
- ราคาเต็ม 999 บาท ราคาพิเศษ 499 บาท
- 1 สิทธิ์ = 1 เครดิต = เปิดตะกร้าคอร์สได้ 1 ตะกร้า
- ตะกร้านี้ไม่ร่วมส่วนลดกับตะกร้าอื่น
- เครดิตโอน ถอน แลก หรือขายต่อเป็นเงินสดไม่ได้
- คอร์สที่ผูกตะกร้าแล้วเปลี่ยนไปผูกคอร์สอื่นไม่ได้

2. การเตรียมคอร์ส
- ผู้ใช้สร้างคอร์สเตรียมไว้ฟรีได้สูงสุด 3 คอร์ส ยังไม่หักเครดิต
- หัก 1 เครดิตเมื่อผูกคอร์สกับตะกร้าสำเร็จเท่านั้น
- ต้องมีอย่างน้อย 1 EP ก่อนเผยแพร่
- หลังผูกตะกร้า แก้ไขได้ 30 วัน หรือจนกว่าจะมียอดขาย แล้วแต่อย่างใดเกิดก่อน

3. บัญชีรับเงินและ API
- เงินค่าคอร์สเข้าบัญชีของเจ้าของคอร์สโดยตรง VisionD ไม่ถือเงินและไม่หักเปอร์เซ็นต์
- เจ้าของคอร์สต้องใช้ EasySlip API Access Token ของตนเอง
- เจ้าของคอร์สรับผิดชอบคีย์ โควตา และค่าใช้จ่าย API

4. การตรวจสลิปและปลดล็อกคอร์ส
- ลูกค้าแนบสลิปหลังชำระเงิน
- ระบบตรวจบัญชีผู้รับ ยอดเงิน เลขอ้างอิง และสลิปซ้ำอัตโนมัติ
- หากข้อมูลถูกต้อง ระบบเปลี่ยนออเดอร์เป็น paid และปลดล็อกคอร์สให้ลูกค้าทันที
- คอร์สจะเข้าเมนู “คอร์สเรียนของฉัน” และเริ่มเรียนได้ทันที
- หาก API อ่านไม่ได้หรือพบความผิดปกติ เจ้าของคอร์สต้องตรวจและอนุมัติหรือปฏิเสธเอง
- ระบบเก็บภาพสลิปทุกภาพเป็นหลักฐานทางการเงิน

5. กฎเนื้อหา
- ล็อกเนื้อหาทันทีเมื่อมียอดขาย หรือเมื่อครบ 30 วัน แล้วแต่อย่างใดเกิดก่อน
- หลังล็อก แก้ไขความผิดพลาดได้ผ่าน VisionD แต่เปลี่ยนสาระหรือเนื้อหาทั้งหมดไม่ได้
- ผู้ขายรับผิดชอบกรณีเปลี่ยนเนื้อหาโดยไม่ได้รับความยินยอมจากลูกค้า และ VisionD มีสิทธิ์ระงับตะกร้าทันที

6. การยืนยันก่อนสั่งซื้อ
- การกดยืนยันหมายถึงผู้ซื้อได้เปิดอ่านเอกสารแนบและรายละเอียดการซื้อครบถ้วนแล้ว
- หากไม่ยืนยัน ระบบจะไม่สร้างคำสั่งซื้อ

============================================================
เอกสารนี้เป็นส่วนหนึ่งของรายละเอียดสินค้าสิทธิ์ลงขายคอร์ส VisionD
