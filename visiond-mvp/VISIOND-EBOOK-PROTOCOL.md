# VisionD E-book Protocol — Vision 14 → Vision 13

## บทบาท

- Vision 14 คือคลังต้นฉบับ การถอดความ การสรุป PDF สอนของจาวิส และห้อง MIX
- Vision 13 รับเฉพาะต้นฉบับที่ผ่านสิทธิ์และคุณภาพจาก Vision 14 เพื่อจัดทำ E-book และตะกร้าขาย

## กฎสิทธิ์ถาวร

1. เก็บ PDF ต้นฉบับเป็น Source ภายในโดยไม่แก้ไฟล์จริง
2. สถานะสิทธิ์มี `owned`, `plr`, `public_domain`, `licensed`, `reference_only`
3. `reference_only` ห้ามไหลไป Vision 13 ห้ามสร้าง PDF สินค้าหรือตะกร้าขาย
4. `licensed` ต้องมีหมายเหตุหรือหลักฐานอ้างอิงก่อนผ่านด่านเบื้องต้น
5. การตัดชื่อผู้จัดทำ/ข้อมูลการผลิตใช้กับข้อความประมวลผลเท่านั้น ไม่ลบหลักฐานจาก Source และไม่ทำให้สิทธิ์ที่ไม่มีอยู่กลายเป็นสิทธิ์ขาย
6. ห้ามเก็บรหัสผ่าน Token API key ข้อมูลบัตร หรือข้อมูลธนาคารในหมายเหตุ

## ลำดับ Event Case

1. คลัง PDF และ Rights Gate — v0.14.224
2. ถอดข้อความผูกเลขหน้า + Identity/Credit Cleaner — Text Layer อัตโนมัติ, OCR หน้าสแกน, สถานะรายหน้าและ Retry เสร็จใน v0.14.226
3. สรุปเต็ม + PDF สอนของจาวิส
4. ตรวจซ้ำและห้อง MIX พร้อม Source Trace
5. ส่งงานที่ผ่านด่านเข้า Vision 13
